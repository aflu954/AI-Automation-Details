Build a RAG-Based Email Customer Support Agent

🎯 Objective
Design a simple AI-powered Customer Support System that can automatically reply to customer emails using a RAG (Retrieval-Augmented Generation) architecture.

The system should retrieve relevant company knowledge before generating accurate and context-aware email responses.

📋 Assignment Task
Design a complete workflow for an AI Customer Support Agent capable of:

Receiving customer emails

Retrieving relevant company information

Generating intelligent responses

Sending replies automatically (or with human approval)
